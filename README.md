# Tsukuyomi - CalendarAssistant

分享你的 Google 日曆，讓訪客輕鬆預約時段。

## 功能特色

- **零註冊** — 不需要建立帳號，所有設定都編碼在連結中，App 不儲存任何資料
- **一鍵分享** — 產生專屬連結與 QR Code，傳給對方就能瀏覽你的行事曆
- **線上預約** — 訪客選取空閒時段後填寫表單，預約資料自動寫入你的 Google Sheet
- **Email 通知** — 有人預約時自動發信通知你
- **手機友善** — 支援 PWA 安裝到主畫面，手機、平板、電腦都能用

## 使用方式

### 第一步：建立你的分享連結

前往 [Tsukuyomi Setup 頁](https://codingcatz.github.io/Tsukuyomi/#/setup)，依照畫面引導完成三個步驟：

1. **貼上 iCal 網址** — 在 Google Calendar 設定中找到「以 iCal 格式建立的公開網址」，頁面上有詳細圖文教學
2. **建立預約接收表格** — 複製 Google Sheet 範本，按照圖解部署 Apps Script（不需要寫程式）
3. **個人設定** — 填寫你的名稱、可預約時段範圍、通知 Email 等

完成後會產生你的**專屬連結**和 **QR Code**。

### 第二步：分享給需要預約的人

把連結或 QR Code 傳給對方，可以放在：
- 社群媒體個人簡介
- 名片
- Email 簽名檔
- 任何你想讓別人找到的地方

### 第三步：訪客預約

對方打開連結後可以：
1. 在**週視圖**瀏覽你未來 28 天的行程概況
2. 點擊日期進入**日視圖**，看到每 30 分鐘的空閒 / 忙碌狀態
3. 選取空閒時段，填寫姓名、聯絡方式、事由
4. 送出預約 — 資料會寫入你的 Google Sheet，你會收到 Email 通知

> 當日不開放預約，訪客只能預約明天之後的時段。

## 常見問題

**Q：我的資料存在哪裡？**
A：App 本身不儲存任何資料。你的日曆設定編碼在連結中，預約資料寫入你自己的 Google Sheet。

**Q：訪客看得到我的行程內容嗎？**
A：訪客只能看到你的時段是「忙碌」還是「空閒」，看不到具體行程標題或內容。

**Q：可以在手機上用嗎？**
A：可以。Tsukuyomi 是 PWA，用手機瀏覽器開啟後可以「加入主畫面」當 App 使用。

**Q：需要付費嗎？**
A：完全免費，開源專案。
